# Elementum Landing Page

A responsive React landing page built from a Figma design as part of a Frontend Developer Internship Assignment.

## Tech Stack

* React
* Vite
* CSS

## Features

* Responsive design
* Reusable React components
* Modern UI
* Hover effects
* Mobile-friendly layout

## Sections

* Navbar
* Hero
* About
* Services
* Customer Review
* Newsletter
* Footer

## Run Locally

```bash
npm install
npm run dev
```
